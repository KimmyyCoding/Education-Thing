# Net Present Value

Net present value (NPV) is the sum of a project's expected cash flows, each discounted back to today, minus the initial investment.

Decision rule: accept a project if its NPV is positive, because it is expected to create more value than it costs.

NPV depends heavily on two inputs that are both estimates: the forecast cash flows and the discount rate. A small change in the discount rate can flip a marginal project from accept to reject.

The internal rate of return (IRR) is the discount rate at which NPV equals zero. NPV and IRR usually agree, but can rank mutually exclusive projects differently.
